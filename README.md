# Sales Forecasting Engine

## Overview

This project was completed as **Case Study Project #3** of the Python Study Group organized by SmartBizCrux Technology.

The objective of this project was to develop a simple Sales Forecasting Engine using only fundamental Python concepts. The program analyzes weekly sales performance, forecasts next week's sales and revenue, updates inventory levels, evaluates business conditions, and generates a professional sales report.

---

## Project Objectives

- Create meaningful variables
- Perform arithmetic calculations
- Forecast sales and revenue
- Update stock inventory
- Determine whether sales targets were achieved
- Check if products require restocking
- Evaluate promotion eligibility
- Generate a professional business report
